# Projeto: Jogo do número secreto

O objetivo do projeto é praticar os conceitos introdutórios de programação como variáveis, funções, e entre outros. A linguagem usada foi JavaScript, e o os arquivos HTML e CSS foram usados como retorno visual do código construído.

## :hammer: Funcionalidades do projeto 
- `Funcionalidade 1`: Testar se o chute número é maior do que o número surpresa
- `Funcionalidade 2`: Modificar as palavras de acordo com a concordância
- `Funcionalidade 3`: Exibir a quantidade de tentativas até a vitória 
- `Funcionalidade 4`: Não permitir que um número se repita em um novo jogo
- `Funcionalidade 5`: Inserir uma voz responsiva
- `Funcionalidade 5`: Limpar campo uma vez realizado o chute
